What are NCM and QMC? Recovery versus MP3 conversion

The outer file format and the audio encoding inside it are different things.

Where these files come from

NCM is associated with certain files saved by NetEase Cloud Music clients. QMC and related extensions are associated with QQ Music clients. Such files can wrap or protect ordinary encoded audio, so a player cannot necessarily treat them as MP3. Platform and client versions vary, and matching extensions do not prove matching internal structures.

What recovering original audio means

For supported files, this tool attempts to undo the recognized outer processing and recover the original audio encoding. If the audio inside is FLAC, the output stays FLAC. If it is MP3 or OGG, the corresponding encoding is kept. Embedded title, artist and artwork may be written to output tags where supported; this does not mean the audio was re-encoded or that the entire output file is byte-identical.

Recovery is different from decoding sound and encoding it again as MP3. The recovery step does not turn all special formats into MP3, improve source quality, or disguise a FLAC by renaming its extension.

Supported extensions are not a guarantee

This tool handles some NCM, legacy QMC and related variants. The converter's Supported formats & details section lists accepted extensions. An accepted extension does not mean that every version is supported. Newer files requiring extra keys or an incompatible structure are rejected as unsupported; there is no account login or key extraction service.

The queue initially shows a file-extension hint and the intended operation. Only the actual result confirms the detected output format. A damaged file and an incompatible version may produce an ambiguous error; the tool cannot always determine one precise cause.

Renaming is not conversion

Renaming song.qmc to song.mp3 changes its name, not its contents. If it still contains a protected wrapper, a player may still be unable to read it. Recovering it requires an implementation for that structure. Converting ordinary OGG, FLAC or WAV to MP3 instead requires decoding and re-encoding; see MP3 quality and transcoding.

If a file is unsupported

Keep the original and use playback, export or authorized download options supplied by the source platform. Do not give account credentials, private files or keys to untrusted services. This tool supplies no music catalog or copyright permission. Only process files you own or are authorized to use and follow the source platform's terms.

Implementation references

Public implementations such as ncmdump and qmc-decoder document historical approaches. Neither their existence nor this site's extension list proves compatibility with every current platform file. For practical steps, read How to use or open the converter.
